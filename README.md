# MoleculeScope

Molecular Research & Protein Analysis Platform

## Overview

MoleculeScope is a full-stack web application
designed to help biology students and researchers
explore proteins, documented variants and
scientific research projects.

## Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js
- JWT Authentication

## Main Features

- User authentication and role management
- Research project management
- Protein exploration
- Variant management
- Scientific analysis reports
